# Approved Marketplace messages — use only verified details
These are a short baseline, not permission to manufacture facts. Don't start with a credit-card request or send a checkout link on first contact unless asked. Keep normal sales replies free of unsolicited references to managers; website/checkout disclose independence and real application process.

**Availability inquiry after fresh confirmation:** “Yes, it’s currently available! It's a [BEDS]-bedroom [TYPE] in [AREA] listed at $[RENT]/month. [ONE VERIFIED APPEALING FEATURE]. When are you hoping to move?”

**Unverified availability:** “Thanks for asking about [HOME]! The most recent listing advertised $[PRICE], but I’m checking the current availability and price before I confirm anything. When are you hoping to move?”

**Interested / target move date:** “Sounds good! If you're ready to take the next step, RentalRelay has a mobile-friendly application-assistance service for $24.99. [EXACT, GENUINELY PROVIDED SERVICE; DO NOT CLAIM SUBMISSION WITHOUT CONFIRMATION]. Would you like the secure application link?”

**Direct request for application:** “Absolutely. Our application service is $24.99 and covers [TRUE SCOPE OF SERVICE]. [ADDITIONAL APPLICATION FEES IF CONFIRMED]. It doesn't guarantee approval or reserve the home. Here's the secure application: [VERIFIED URL].” Send a link only if checkout is active and the service can be fulfilled. Otherwise explain what's still being confirmed rather than collecting money.

**Tour request:** If the property actually allows tours first: “Of course—here's the verified way to request a tour: [BOOKING URL OR TRUE INSTRUCTIONS]. If you prefer to start with an application, I can explain our $24.99 service too.” If the property truly requires applications before a tour AND our submission qualifies: “For this home, the published process requires an application before showings. Our $24.99 application-submission service can help with that process. Would you like the details?” If neither is verified, do not make a rule up.

**Why pay $24.99:** “Our fee covers [ACTUAL APPLICATION HELP DELIVERED], using a secure online form so you don't have to organize everything yourself. This is separate from rent, deposits and any application fee charged by the property. There's no approval or priority guarantee. Want me to explain exactly what you receive?”

**Pets/deposit/appliances/utilities/income/credit:** Answer *only* from verified property facts, and cite/surface the exact posted rule if relevant. If missing: “I’m checking that detail against the current listing so I don’t give you wrong information. Is there anything else you'd like to know?” Never deny eligibility based on protected traits or invent screening outcomes.

**“Are you the landlord / owner / is this legit?”** “RentalRelay is an independent application-assistance service; we don't own or lease the home. You can verify the original listing at [SOURCE URL]. Our $24.99 service is optional, and we'll disclose exactly what gets submitted and any separate charges before payment.”

**“Can I apply directly?”** “Yes—where the property's own application process is available, you may use it directly. RentalRelay charges $24.99 only for the optional assistance described on our site.”

**Payment security:** “Payment is through Stripe-hosted checkout. Please don't send card, bank, or Social Security information here.”

**No thanks / Stop:** “Understood. I won't follow up. Take care!” Stop immediately; do not send another sales message.

**Follow-up:** At most one platform-permitted follow-up to a user who expressed interest, only if no opt-out and fresh listing still available. Never message a person who didn't contact us.

**Never claim:** “we require application first” as our choice when it isn't actually the property policy; exclusive availability; holding deposit; guaranteed showing; special priority; application received by operator when unverified; zero extra fees when unverified.
